# Kunchapu Vamsi Krushna — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. It is designed for easy hosting on GitHub Pages and does not require a build step or package installation.

## Preview locally

Open `index.html` in a browser, or run a local static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Download and extract this project.
2. Add your real resume PDF to this folder and name it `Vamsi_resume.pdf` (the download button links to that filename).
3. Check your contact links and update any details you want to change.
4. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the resume PDF to your GitHub repository.
5. In GitHub, open **Settings → Pages**, choose the `main` branch and `/ (root)` folder, then save.

## Personalize before publishing

- The current email and GitHub/LinkedIn URLs are based on the public portfolio previously provided.
- Education reflects the existing portfolio's stated university and final-year status; verify that it is still accurate.
- The first project card links to the existing portfolio repository. The second card is explicitly a placeholder until you add another real project.
- Skills are limited to the skills provided: Python, HTML, CSS, JavaScript, C, Java, and OOP.
- The superhero-comic feel is made with original CSS cityscape and abstract web effects; there are no character images or profile photo.

## Files

- `index.html` — page content and sections
- `styles.css` — theme, original cityscape background, responsive layout, and animation styling
- `script.js` — mobile navigation, reveal effects, active navigation, and current year
